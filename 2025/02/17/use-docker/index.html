Ubuntu 22.04 Docker的安装与简单使用

发表于 2025-02-17 更新于 2025-04-10 分类于 文章 ， 技术 ， Linux 运维

前言

  • Docker简介
    Docker是一个用于开发、部署和运行应用程序的开放平台，它利用容器化技术，将应用程序及其依赖项打包成一个独立的容器，从而实现应用在不同环境中的一致运行。
    通过运用容器技术，极大地减小了项目配置地复杂性。在传统的虚拟机部署方式中，由于开发或测试环境的不同，导致项目在迁移时出现诸多兼容性问题（如果系统版本、软件环境依赖的不同）。同时，容器具有轻量级的特性，即容器内只含有满足运行时所需的最基本的配置。

  • 核心概念
    镜像（Image）：是一个只读的模板，类似于虚拟机的镜像。它包含了运行应用程序所需的一切，如代码、运行时环境、库、环境变量和配置文件等。可以将镜像看作是容器的 “蓝图”，通过镜像可以创建出多个相同的容器。例如，一个基于 Ubuntu 系统并安装了 Python 环境的镜像，就可以用来创建运行 Python 应用的容器。（这里介绍一个国内可用的Docker镜像站渡渡鸟镜像同步站）
    容器（Container）：是镜像的一个运行实例，它是一个独立的进程，与宿主机以及其他容器隔离。容器之间可以通过网络进行通信，并且可以根据需要启动、停止、删除。容器的启动速度非常快，通常在毫秒级别，因为它不需要像虚拟机那样启动一个完整的操作系统。例如，基于上述 Python 镜像创建的容器可以运行具体的 Python 脚本或 Web 应用。
    仓库（Repository）：用于存储和分发 Docker 镜像的地方，类似于代码仓库。有公共仓库（如 Docker Hub）和私有仓库之分。公共仓库中包含了大量的官方和社区维护的镜像，用户可以免费下载使用；私有仓库则用于企业或组织内部存储和管理自己的镜像，保证镜像的安全性和隐私性。
    简言之：镜像制定模板，容器依据镜像创建实例，仓库则负责管理镜像。
